# LUNA AI — Таролог & МАК-Проводник

Интерактивное веб-приложение и Telegram-бот: ИИ-таролог и проводник по метафорическим ассоциативным картам (МАК). Персональные расклады, Карта Дня, расчёт Аркана Судьбы, глубокий психологический самоанализ и дневник.

Работает как обычный сайт и как Telegram Mini App.

## Возможности

- 🔮 **Расклады Таро** — несколько готовых раскладов (Три Времени, психика, выбор и др.), трактовка каждой карты в позиции
- 🧩 **МАК-самоанализ** — интерактивный диалог с ИИ-коучем по метафорическим картам
- 🌅 **Карта Дня** — энергия дня, коучинговый вопрос, аффирмация
- ♈ **Аркан Судьбы** — расчёт по дате рождения (нумерология Таро + знак зодиака, стихия, планета)
- 📖 **Дневник** — сохранение истории раскладов
- 🤖 **Telegram-бот** — живой бот (long-polling) с командами:

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и описание возможностей |
| `/help` | Список команд |
| `/card` | 🌅 Карта Дня |
| `/tarot` | 🔮 Расклад «Три Времени» (Прошлое — Настоящее — Будущее) |
| `/mac` | 🧩 Метафорическая карта с вопросом для самоанализа |
| `/destiny 01.01.1990` | ♈ Аркан Судьбы по дате рождения (дата запоминается) |

Команды бота работают локально на данных колод (без вызовов AI); свободные вопросы обрабатывает Gemini.

## Запуск

**Требования:** Node.js 18+

```bash
npm install
cp .env.example .env   # заполнить переменные
npm run dev            # http://localhost:3000
```

### Переменные окружения (.env)

| Переменная | Обязательна | Назначение |
|---|---|---|
| `GEMINI_API_KEY` | Да | Ключ Google Gemini API |
| `APP_URL` | Для WebApp | Публичный HTTPS-URL приложения (для кнопки WebApp в боте) |
| `TELEGRAM_BOT_TOKEN` | Нет | Токен бота из @BotFather; можно задать и через веб-интерфейс |
| `ADMIN_SECRET` | Нет | Секрет для управления токеном бота через веб-интерфейс |
| `PORT` | Нет | Порт сервера (по умолчанию 3000) |

### Подключение Telegram-бота

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), скопируйте токен.
2. Вставьте токен в раздел «Telegram Интеграция» веб-приложения или в `.env`.
3. Для кнопки WebApp задайте `APP_URL` — публичный HTTPS-адрес приложения.

### Продакшен-сборка

```bash
npm run build   # клиент → dist/, сервер → dist/server.cjs (без sourcemap)
npm start       # NODE_ENV=production, слушает process.env.PORT
```

## Деплой на VPS (текущий контур)

Сервер: Ubuntu 26.04, `<VPS_IP>`. Доступ — только по SSH-ключу под пользователем `glm` (root-вход отключён); ключи и реквизиты лежат локально в `vps-access/` и в git не попадают.

| | v1 (не трогаем) | v2 (этот репозиторий) |
|---|---|---|
| Код на сервере | `/root/app` | `/root/app-v2` |
| Процесс | pm2 `luna-tarot` | pm2 `luna-v2` |
| Порт | 127.0.0.1:3000 | 127.0.0.1:47321 |
| Домен | `lunalis.ru`, `myluna.ru` | `v2.lunalis.ru` (нужна A-запись → <VPS_IP>) |

Оба Node-сервера слушают только `127.0.0.1` — наружу отдаёт nginx (80/443, Let's Encrypt). Python-бэкенд Mini App (`/opt/luna-ai-py`, systemd `luna-ai`, порт 8000) общий и относится к v1.

Обновление v2 на сервере:

```bash
ssh -i vps-access/id_ed25519_glm_vps glm@<VPS_IP>
cd /root/app-v2 && sudo git pull && sudo npm run build && sudo pm2 restart luna-v2
```

## Защита сервера

- **ufw active**: снаружи только 22 (LIMIT — rate-limit подключений), 80, 443.
- **fail2ban**: jail `sshd` — бан после 5 неудачных попыток за 10 минут (1 час, с эскалацией).
- **SSH**: вход только по ключу (`passwordauthentication no`), `PermitRootLogin no`, OpenSSH 10.2p1.
- Node-приложения и Python-бэкенд не торчат в интернет напрямую — только через nginx.

## Безопасность приложения

- Все вызовы Gemini выполняются на сервере — API-ключи не попадают в клиентский бандл.
- `POST /api/telegram/set-token` защищён: при заданном `ADMIN_SECRET` запрос должен содержать заголовок `x-admin-secret`; без секрета эндпоинт принимает запросы только с localhost.
- Rate limiting: 10 запросов/минуту на IP для AI-эндпоинтов (429 при превышении).
- `.env` исключён из git (`.gitignore`).

## Стек

React 19 + Vite + Tailwind CSS 4 + Express + Gemini API (`@google/genai`). Сервер запускается через `tsx` (dev) и собирается esbuild (prod).
